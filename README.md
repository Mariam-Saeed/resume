# Resume

My resume, written in LaTeX and automatically built and published as a PDF using GitHub Actions and GitHub Pages.

**[View Resume (PDF)](https://mariam-saeed.github.io/resume/resume.pdf)**

## Tech Stack

- LaTeX (XeLaTeX)
- GitHub Actions
- GitHub Pages

## How It Works

1. Edit `resume.tex`.
2. Open a pull request to validate the LaTeX build.
3. Merge into `main` to automatically generate and deploy the updated PDF.

The PDF is published through GitHub Pages without committing generated files to the repository.
